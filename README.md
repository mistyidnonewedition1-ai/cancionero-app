# 🎸 Cancionero

Apprendre l’espagnol natif avec des chansons : traduction vers par vers, exercices à trous, vocabulaire, révision espacée et prononciation (audio + transcription figurée).

## Utilisation
Ouvre `index.html` dans un navigateur, ou active GitHub Pages (Settings → Pages → branche `main`, dossier `/root`).

## Notes
- Les données sont stockées dans le navigateur (`localStorage`).
- Le bouton « Corriger et expliquer avec Claude » n’apparaît que dans Claude.ai ; le reste fonctionne partout.
- Aucune parole de chanson n’est fournie : colle celles de ton choix.
