# 🎸 Cancionero · Chansonnier

Apprendre l’espagnol (francophones) ou le français (hispanophones) avec des chansons.

- `/` : choix de la langue (mémorisé, bouton 🌍 pour changer)
- `/es/` : Cancionero (apprendre l’espagnol)
- `/fr/` : Chansonnier (aprender francés)

Les données sont stockées dans le navigateur (localStorage).
